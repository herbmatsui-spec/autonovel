# サブテキスト・決定論的リライトエンジン (SubtextEngine) 運用ガイド

## 1. 概要
`SubtextEngine` は、LLM呼び出しを行わずに、正規表現ベースの決定論的ルールによって台詞の「説明過剰」「感情の直接吐露」「陳腐な因果関係」を検知し、行間（サブテキスト）・沈黙・身体動作（ビート）へと自動リライトするエンジンです。

## 2. コア設計思想
1. **Show, Don't Tell**: 「私は悲しい」と語らせるのではなく、拳を握りしめ、視線を落とす動作に置換。
2. **沈黙の価値**: 3行以上の説明ゼリフを1行に凝縮し、前段を息を呑むト書きに置換。
3. **決定論的再現性**: 同じコンテキスト（話者・関係性・ターン番号）が与えられれば、乱数シードが固定され同一の出力を保証。
4. **安全フォールバック**: いかなる正規表現エラーや例外が発生しても元の台詞を保持し、生成パイプラインを中断させない。

## 3. コアルール一覧 (Step 7 - 15)
| ID | ルール名 | 対象パターン例 | 変換後演出 |
|---|---|---|---|
| `rule_01_explanatory_compress` | 説明セリフ圧縮 | 3行連続の台詞 `「...」\n「...」\n「...」` | 最後の1行のみ残し、前段を緊張ビートに変換 |
| `rule_02_emotion_to_action` | 感情直撃語の動作化 | 「私は悲しい」「怒っている」 | 「……」＋奥歯を噛み締めるト書き |
| `rule_03_causal_to_irony` | 因果接続詞の皮肉化 | 「なぜなら君が〜だからだ」 | 「……好きにすればいいわ」等の皮肉定型文 |
| `rule_04_subjective_internalize` | 主観表明の内在化 | 「私は〜と思う/確信しています」 | （……確信しげな素振りを見せ、言葉を飲み込む） |
| `rule_05_threat_subtext` | 脅迫の含み持たせ | 「絶対に殺してやる」 | 「……二度目はない」——冷笑を浮かべ背を向ける |
| `rule_06_compliance_subvert` | 同意の皮肉・無言化 | 「はい」「わかりました」 | 60% 皮肉承諾 / 40% 無言の会釈 |
| `rule_07_address_distance` | 呼称・敬称距離感 | 「お前」「君」 | 敵対関係時は「貴方」等へ文脈変化 |
| `rule_08_apology_deflection` | 謝罪の受容拒否 | 「ごめんなさい」 | 「……謝られても、何も戻らない」 |
| `rule_09_hesitation_stutter` | 吃音の生理動作化 | 「あっ、あっ」 | （息を詰まらせ、喉をかすかに震わせる） |
| `rule_10_secretive_whisper` | 密談前置きの緊迫化 | 「ここだけの話だけど」 | 「……壁に耳があるわ」 |
| `rule_11_rhetorical_evasion` | 質問返し | 「どうしてそんなことを？」 | 「……それを知って、どうするつもり？」 |
| `rule_12_condescending_polite` | 慇懃無礼化 | 「ご親切にどうも」 | 「……余計なお気遣い、感服いたしますわ」 |
| `rule_13_gaze_aversion` | 視線逸らしト書き | 「見ないでよ！」 | （咄嗟に顔を背け、手の甲で表情を隠す） |
| `rule_14_monologue_cutoff` | 独り言の遮断 | 「独り言さ」 | 「……なんでもない。忘れて」 |
| `rule_15_unspoken_tension` | 緊迫の境界線提示 | 「言いたいことはそれだけか？」 | 「……それ以上は、お互いのためにならない」 |

## 4. ルール追加手順
1. `config/subtext_rules.yaml` に新しいルールエントリを追加
2. `tests/narrative/subtext_engine/` に単体テストを追加
3. `tests/golden/subtext_before_after/` に回帰用ゴールデンケースを追加
4. `python scripts/analyze_rule_conflicts.py` で他ルールとの競合を検査

## 5. ベンチマーク
- 基準値: 1万ブロック処理 <= 100ms
- コマンド: `python benchmarks/subtext_engine_bench.py`
