# セマンティックキャッシュ検討（オプション）

## アプローチ
プロンプトをベクトル化し、類似度検索で過去の結果を再利用する。

### 手順
1. 入力プロンプトを埋め込みモデル（例: Sentence-BERT）でベクトル化
2. ベクトルストア（例: FAISS, Annoy, またはシンプルな線形探索）で類似プロンプトを検索
3. 類似度が閾値を超える過去の結果をキャッシュヒットとして再利用
4. 閾値に満たない場合は通常の生成プロセスを実行し、結果をベクトルストアに追加

## 課題
- 類似度閾値の設定: too low → キャッシュヒット率低下, too low → 不適切な結果の再利用
- ベクトルストアのコスト: 追加のメモリおよび計算リソース
- 遅延増加: ベクトル検索によるオーバーヘッド
- ベクトルストアの更新戦略: 古いエントリの削除・更新
- マルチ言語対応: 日本語プロンプトに適した埋め込みモデルの選択

## 推奨
- Phase 3 ではオプション機能として検討に留める
- Phase 4 以降でプロトタイプ実装を行い、効果を測定する
- 代替案として、キーワードベースの類似マッチングやルールベースのグループ化を検討する
- 実装する場合は、ヒット率とレイトレンシのトレードオフを評価するためのベンチマークを設けること

## 実装イメージ（概念図）
```
入力プロンプト
    ↓
[ベクトル化]
    ↓
[類似度検索]
    ↓
[ヒット?] --yes--> [過去の結果を返却]
    ↓ no
[通常の生成プロセス]
    ↓
[結果をベクトルストアに追加]
    ↓
最終出力
```
