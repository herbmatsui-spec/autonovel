# 小説投稿プラットフォーム向けフォーマットガイド (Publishing Guide)

AutoNovel では、執筆した小説を各Web小説投稿サイト（小説家になろう、カクヨム、アルファポリス、Amazon KDP、青空文庫形式）へ最適なレイアウトで出力・エクスポートするプラットフォームフォーマッターを備えています。

---

## 1. 対応プラットフォームとルビ・傍点記法

| プラットフォーム | ルビ記法 | 傍点（圏点）記法 | 内部変換仕様 |
|---|---|---|---|
| **小説家になろう** | `|漢字《ルビ》` | `|強《・》|調《・》` | ルビは半角パイプに統一。傍点は1文字ずつのルビに展開 |
| **カクヨム** | `|漢字《ルビ》` | `《《強調》》` | カクヨム公式記法に完全準拠 |
| **アルファポリス** | `#漢字(ルビ)#` | `#強(・)##調(・)#` | ハッシュ＋丸括弧記法に自動トランスパイル |
| **青空文庫形式** | `｜漢字《ルビ》` | `［＃傍点］強調［＃傍点終わり］` | 全角パイプおよび青空文庫注記タグに変換 |
| **Amazon KDP (EPUB)** | `｜漢字《ルビ》` | `<span class="bouten">` / CSS | 縦書きEPUB 3組版エンジンでXHTMLに変換 |

---

## 2. タイポグラフィ自動正規化ルール

AutoNovel の `PlatformFormatter` は、Web小説の可読性を最大化するため、以下の整形ルールを自動適用します：

1. **会話文の頭下げ禁止**:
   - `「` `『` `（` `【` などの括弧で始まる会話行は、行頭インデントを行いません。
2. **地の文（段落頭）の全角スペース付与**:
   - 通常の地の文段落の先頭には、必ず全角スペース（`　`）を1文字挿入します。
3. **連続空行の抑制**:
   - 画面のスクロール負担を軽減するため、3行以上の連続空行は自動的に最大2行の空行（改行3つ）に正規化します。
4. **三点リーダー（…）とダッシュ（―）の偶数揃え**:
   - 日本の出版・Web小説マナーに則り、奇数個の三点リーダーは偶数組（`……`）に補正します。

---

## 3. 各サイトの文字数・タイトル制限一覧

| プラットフォーム | タイトル上限 | あらすじ上限 | 備考 |
|---|---|---|---|
| **小説家になろう** | 100文字 | 推奨1,000文字以内 | タイトル超過時は警告が出力されます |
| **カクヨム** | 100文字 | 10,000文字 | 詳細なあらすじ・登場人物紹介を記載可能 |
| **アルファポリス** | 100文字 | 規定なし | タイトル超過チェックあり |

---

## 4. エクスポート方法

1. **ワンクリックプレビュー**:
   - エディタまたはエクスポートパネルから「Web小説投稿フォーマット」を選択し、プラットフォームを選ぶと、即座に整形後テキストを画面で確認・クリップボードにコピーできます。
2. **一括ZIPダウンロード**:
   - `00_作品情報・あらすじ.txt` および、各話がナンバリングされたテキストファイル（`001_第1話.txt` など）が整理されたZIPアーカイブを出力できます。
