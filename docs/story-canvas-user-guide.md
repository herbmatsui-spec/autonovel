# ストーリーキャンバス ユーザーガイド

## 概要

ストーリーキャンバスは、作品の構造を視覚的に編集・編集するためのインタラクティブなツールです。
エピソード、キャラクター、構造要素をノードとして配置し、それらの間の関係をエッジで結びつけることで、
物語の全体像を把握し、プロットホールやキャラクター発展の機会を見つけることができます。

## ノードタイプ

| タイプ | アイコン | 説明 | データフィールド |
|------|----------|------|------------------|
| 🎯 前提 (Premise) | 🎯 | 作品の核となるコンセプトやテーマ | concept, synopsis |
| 🎪 幕 (Act) | 🎪 | 三幕構成等の大構造 | structure, beat |
| 📖 エピソード (Episode) | 📖 | ストーリーの各話 | tension, is_catharsis, summary, detailed_blueprint, next_hook |
| 🎬 シーン (Scene) | 🎬 | エピソード内のシーン | (将来実装) |
| 👤 キャラクター (Character) | 👤 | 物語に登場する人物 | role, traits, relationships, background |
| ⚡ 伏線 (Foreshadow) | ⚡ | 後の展開に影響を与える要素 | strength, description, payoff_location |

## エッジタイプ

| タイプ | 説明 | 視覚スタイル |
|------|------|--------------|
| ➡️ フロー (Flow) | 時系列の流れ（エピソード順） | 実線 |
| 🔗 部分Of (Part_of) | 包含関係（アクト→エピソード等） | 実線 |
| 👁️ POW (POV) | エピソードの視点キャラクター | 実線 |
| 🔗 依存 (Dependency) | 依存関係（伏線→回収等） | 破線 (4 2) |
| 💞 関係 (Relationship) | キャラクター間の関係 | 破線 (4 2) |
| ⚡ 伏線 (Foreshadow) | 伏線とその回収 | 破線 (8 4) |

## 基本操作

### ノードの作成
1. ツールバーの「+エピソード」または「+キャラクター」ボタンをクリック
2. または、既存ノードの「+」ボタンをクリックして新しいノードを作成
3. ノードはビューポートの中心に配置されます

### ノードの選択
- ノードをクリックすると選択状態になり、右側インスペクターパネルに詳細が表示されます
- 複数選択は現在サポートされていません（将来実装予定）

### ノードの移動
1. ノードをクリックしてドラッグします
2. ドラッグ中にノードが追従します
3. マウスボタンを離すと位置が確定し、自動的に保存されます

### エッジの作成
1. ノードの「+」ボタンをクリックしてリンクモードを開始
2. 他のノードをクリックすると、その間にエッジが作成されます
3. または、キーボードの「L」キーでリンクモードをトグルし、その後ノードをクリック

### ノード・エッジの削除
- ノード: ノード左下の「𗚖」ボタンまたはDeleteキー
- エッジ: エッジ中央に表示される「×」ボタン（ホバー時に表示）

### ビューポート操作
- パン: 右ドラッグ（またはスペースキー＋ドラッグ）
- ズーム: マウスホイール
- リセット: 「ビューポートリセット」ボタン

## 高度な機能

### キャラクター弧の視覚化
エキスパートモードでは、キャラクターノードの下にキャラクター弧のスパークラインが表示されます。
これにより、キャラクターの感情的変化や発展を時系列で把握できます。

### ナラティブタイムライン
エキスパートモードでは、キャンバス下部にテンションカーブが表示されます。
これにより、物語全体の緊張感の変化を把握できます。

### キーボードショートカット
- `L`: リンクモードトグル
- `Delete`: 選択中のノードを削除
- `Escape`: リンクモードキャンセル
- `Space` + ドラッグ: ビューポートパン

## シード機能

「🌱 キャンバスを初期化 (Seed)」ボタンをクリックすると、以下のデータから自動的に初期キャンバスが生成されます：

1. **前提ノード**: 作品のコンセプト・あらすじから生成
2. **幕ノード**: 三幕構成（導入・展開・結末）から生成
3. **エピソードノード**: 既存のプロットデータから生成（エピソード番号順に配置）
4. **キャラクターノード**: 既存のキャラクターデータから生成
5. **エッジ**: エピソード間のフロー、アクト・エピソード間の包含関係

## 実装詳細

### データ永続化
- ノードの位置変更は即座にバックエンドに保存されます
- ノードのラベル・データ変更はインスペクターでの編集時に保存されます
- エッジの作成・削除は即座にバックエンドに反映されます

### パフォーマンス
- 大量のノード・エッジでもスムーズな操作を実現するため、描画は最適化されています
- ズーム・パン操作はGPUアクセレレーテッドのCSS変換を使用しています

## トラブルシューティング

### データが読み込まれない
1. 作品が選択されているか確認してください
2. コンソールでAPIエラーがないか確認してください
3. ページを再読み込みしてください

### 操作が遅い
1. ブラウザのハードウェアアクセラレーションが有効か確認してください
2. 他のタブやアプリケーションを閉じてリソースを解放してください
3. ノード数が極端に多い場合は、ビューをフィルタリングする機能をご利用ください（将来実装予定）
