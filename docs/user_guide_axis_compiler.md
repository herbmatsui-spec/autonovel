# ユーザーガイド：多軸プロンプトコンパイラ & ロック・ランダム化

## 概要
本機能では、小説生成のあらゆる設定項目（出力モード、テーマ、ジャンル、世界観、読者層、時代、結末、語り口、登場人物、万能インプット、補足メモ）を **軸** として管理し、それらを統合して LLM に送信するプロンプトを自動生成します。

各軸には **ロック** 機能があり、ロック中の項目はランダム化やリセットから保護されます。また、プリセットのエクスポート/インポートで設定を共有できます。

---

## 画面構成

### 左ペイン：軸セレクタ
各軸はカード形式で表示され、以下の操作が可能です。

| アイコン | 操作 | 説明 |
|---|---|---|
| 🔒 / 🔓 | **ロック切替** | クリックでロック状態を切り替え。ロック中は値変更・ランダム化不可。 |
| 🎲 | **ランダム化** | その軸のみプリセットからランダムに値を設定。ロック中は無効。 |
| ↩ | **リセット** | デフォルト値（初期値）に戻す。ロック中は無効。 |
| 入力欄 | **値編集** | テキストエリアまたはセレクトボックスで直接値を入力。ロック中は編集不可。 |

### 上部：出力モードチップ
15 種類の出力モード（4コマ、小説、短編、脚本など）から選択。選択中は青色ハイライト。

### ツールバー
| ボタン | 機能 |
|---|---|
| 🎲 全項目ランダム | **未ロック** の全軸を一括でランダム化。 |
| 📤 プリセット出力 | 現在の全軸（値・ロック・デフォルト）を JSON ファイルとしてダウンロード。 |
| 📥 プリセット読込 | JSON ファイルを選択して全軸を一括適用。 |

### 下部：コンパイル済みプロンプト プレビュー
「再コンパイル」ボタンで現在の軸設定から生成されるプロンプト全文を表示。生成前にプロンプトを確認可能。

---

## 基本操作フロー

1. **出力モード選択** – 書きたい形式のチップをクリック。
2. **軸の設定** – 各カードでテーマ、ジャンル等を入力またはセレクト。
3. **ロック** – 固定したい項目は 🔒 をクリック（再クリックで解除）。
4. **バリエーション生成** – 🎲 で単体ランダム、または「全項目ランダム」で一括。
4. **プリセット保存** – 「プリセット出力」で JSON 保存、チーム共有やバックアップに。
5. **プロンプト確認** – 「再コンパイル」で生成されるプロンプトをプレビュー。
6. **生成実行** – 通常の生成ボタン（既存の執筆開始フロー）で小説生成。

## ロックの永続化
- ロック状態は **ブラウザの localStorage** に自動保存され、次回起動時に復元されます。
- サーバー側にも `books.axis_lock_flags` カラムとして保存されるため、複数デバイス・複数ユーザー間で同期されます（SSE 経由でリアルタイム反映）。

---

## プリセット JSON 形式
```json
{
  "axisSelections": {
    "theme": { "value": "冒険", "locked": false, "defaultValue": null },
    "genre": { "value": ["ファンタジー"], "locked": true, "defaultValue": null },
    ...
  }
}
```
- `value` は文字列、文字列配列、または null。
- `locked` は boolean。
- `defaultValue` はリセット時に使用される値（通常は初期値）。

## 開発者向け：テンプレートカスタマイズ
出力モードごとのプロンプトテンプレートは `prompts/templates/compiler/<mode>.j2` に Jinja2 形式で配置されています。詳細は [`docs/prompt_compiler.md`](prompt_compiler.md) を参照してください。

## よくある質問

**Q. ロックしても値が変わってしまう**  
A. ロックアイコンが 🔒 になっているか確認してください。ロック中は入力欄が半透明になり編集不可になります。

**Q. 「全項目ランダム」でロック項目が変わってしまう**  
A. バグの可能性があります。開発者に報告してください。

**Q. プリセットをインポートしたらロックが解除された**  
A. インポート時は JSON に含まれる `locked` 値が適用されます。JSON に `locked: true` が含まれていない場合は解除されます。

**Q. サーバー再起動後にロックが消えた**  
A. ブラウザの localStorage がクリアされたか、別ブラウザでアクセスした可能性があります。サーバー側の `axis_lock_flags` から復元されるはずです（SSE 接続時に同期）。

## トラブルシューティング
- **コンパイルエラー** → ブラウザコンソールのネットワークタブで `/api/prompt/compile` のレスポンスを確認。
- **SSE 接続エラー** → ネットワークタブで `/api/v1/events/stream` が `200` か確認。ファイアウォールやプロキシが SSE を遮断していないか。
- **ランダム化が動かない** → `/api/prompt/randomize/{axis}` が 400 を返していないか確認。プリセット辞書に該当軸が定義されているか。
