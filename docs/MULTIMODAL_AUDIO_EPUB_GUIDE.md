# AutoNovel マルチモーダル（音声・商用EPUB 3組版）利用ガイド

## 1. VOICEVOX 音声合成エンジンの連携
- **概要**: チャプター本文から台詞・地の文を自動抽出し、VOICEVOX サーバー経由で自然な日本語キャラクター音声を合成します。
- **設定**:
  - `VOICEVOX_URL`: `http://localhost:50021`（ローカルエンジン起動先）
  - `ENABLE_AUDIO_SYNTH`: `true` に設定すると実機合成、`false` の場合はオフライン・テスト用モック音声クライアント（無音WAV）が自動選択されます。
- **話者マッピング**:
  - ナレーション: ずんだもん（ノーマル、ID: 3）
  - ヒロイン/女性主役: 四国めたん（ノーマル、ID: 2）
  - 主人公/男性: 青山龍星（ID: 13）

## 2. 商用縦書き EPUB 3 組版仕様
- **概要**: 外部ライブラリ（ebooklib等）に一切依存せず、Pure Python で規格厳格準拠の縦書きEPUB 3アーカイブを生成します。
- **機能**:
  - `writing-mode: vertical-rl;`（縦書き標準、右開き）
  - ルビ対応: `｜親文字《るび》` および `漢字《るび》` を `<ruby>` タグに自動変換
  - 傍点対応: `《《強調》》` を `<span class="bouten">`（ごま点）に変換
  - 縦中横対応: 2桁半角数字（10〜99）および感嘆符（!?、!!）を `<span class="tcy">` に変換
  - 規格必須構造: `mimetype`（先頭非圧縮）、`META-INF/container.xml`、`nav.xhtml`、旧規格互換 `toc.ncx` の二重生成
