# 第1話：封印の祭壇

薄暗い洞窟の奥、古びた石扉の前に立ったアルトは、静かに息を呑んだ。  
手にした魔導剣が微かに共鳴し、暗闇を青白い光が照らし出す。  
「ここが、封印の祭壇か……」  
扉に刻まれた古代文字が突如として紅く輝き、不気味な地鳴りと共に守護獣が姿を現した。  

巨大な石像のような獣は、幾重にも重なった魔法陣の上で息を吹き返す。その瞳は魔力の奔流を湛え、アルトの存在を即座に認識した。  
「侵入者か。それとも、鍵を持つ者か」  
獣の声は岩を砕くような低音で、洞窟全体に響き渡る。  

アルトは剣を構え、魔力を剣身に注ぎ込む。青白い光が強まり、剣先から魔力の奔流が放たれる。  
「どちらでもいい。俺がここで止まることはない」  

守護獣が前脚を振り上げ、大地を砕く一撃を放つ。アルトは紙一重で回避し、獣の懐へと潜り込んだ。魔導剣が獣の核心——胸部の魔法陣を捉える。  
「砕け！」  

轟音と共に獣の動きが止まる。紅き光が青白く変わり、扉の封印が解かれていく。  
「行け。その先に、お前の求める真実がある」  
獣の声が、今度は穏やかに、アルトの背中を押した。  

石扉が音もなく開き、その奥から溢れんばかりの星光がアルトを包み込んだ。

# 第2話：星の巫女と約束の剣

星光に満ちた広間の中央、水晶の台座の上に一振りの剣が鎮座していた。  
その剣身は夜空のように深く、無数の星屑を内包しているかのように煌めく。  

「よくぞ来たね、旅人の剣士」  
透き通るような声が、アルトの脳裏に直接響く。声の主は、台座の前に佇む銀髪の少女——星の巫女、セレネだった。  
彼女の瞳は星々を映し、その指先からは微かな魔力の粒子が零れ落ちている。  

「星核の剣……これが、世界を救う鍵なのか？」  
アルトが問うと、セレネは静かに頷き、剣に手を伸ばした。彼女の指先が剣柄に触れた瞬間、広間全体が強烈な光に包まれる。  

「そう。これは『星詠みの剣・アストライア』。古の文明が、世界を侵食する『虚無』に対抗するために造った最後の希望」  
セレネの声には、千年の孤独と、揺るぎない決意が宿っていた。  

「だが、この剣を扱えるのは『星の血を引く者』だけだ。お前は……違う」  
「俺は、自分の剣で道を切り開いてきた。血筋など関係ない」  
アルトの言葉に、セレネは微かに驚いたような表情を見せ、やがて穏やかな笑みを浮かべた。  

「なるほど。お前の魔導剣が、この剣と共鳴した理由がわかった」  
セレネが星詠みの剣を掲げると、アルトの魔導剣が暴れるように震え、二つの剣の間に光の帯が生まれる。  

「共鳴（レゾナンス）だ。お前の剣は、星詠みの剣の『欠片』だったんだ」  
「欠片……だと？」  
「そう。世界が砕かれたとき、星詠みの剣は幾つもの欠片に分かたれた。お前が持つのはその一つ——『暁の欠片』だ」  

セレネがアルトの剣に触れると、二つの剣が光の糸で結ばれ、一つの大きな魔法陣を描き出す。  
「これからは、二人で戦うことになる。虚無の眷属たちが、すでに動き出しているからね」  

広間の壁面に、世界地図のような投影が浮かび上がる。いくつもの赤い点が、大陸各地で脈打っている。  
「それぞれの欠片を回収し、星詠みの剣を完全な形に戻す。それが、世界を救う唯一の道だ」  

アルトは自分の剣、そしてセレネの剣を見比べ、固く頷いた。  
「分かった。俺の剣で、世界の夜明けを切り開く」

# 第3話：暁の剣、虚無を断つ

氷結の王都——永遠の冬に閉ざされた都市の尖塔の頂上で、アルトとセレネは「影の貴族」と対峙していた。  
漆黒のマントを纏った貴族は、その手に歪んだ剣——虚無の欠片を握りしめている。  

「星の巫女と、欠片の継承者か。愚かな抵抗だ」  
貴族の声は、無数の亡霊の囁きのように重なり合う。  
「虚無はすべてを無に帰す。抗うことは、ただ苦しみを延ばすだけだ」  

「苦しみか。それも、生きてる証だ」  
アルトは魔導剣——暁の欠片を構え、セレネと背中合わせになる。  
「俺たちは、明日への道を選ぶ」  

戦端は、貴族が放った影の矢で開かれた。無数の黒い光槍がアルトらを襲う。  
セレネが星詠みの剣を振るうと、星屑の盾が展開し、矢を弾き返す。  
「アルト、今だ！」  

アルトはセレネの作った隙を突き、貴族の懐へと飛び込む。二つの剣——暁の欠片と星詠みの剣が、同時に貴族の虚無の剣を捉える。  

「共鳴（レゾナンス）！ 全解放！」  

二つの剣から溢れ出した光が、一つの巨大な剣光となって貴族を貫く。  
「ぐわあああっ——！」  
貴族の悲鳴が、王都の氷壁を砕く。漆黒のマントが灰となり、虚無の欠片が光の粒子となってアルトの剣へと吸い込まれていく。  

「二つ目の欠片……『夜の欠片』を回収した」  
セレネが息を整えながら、アルトの剣——今や二つの欠片を宿した剣を見つめる。  
剣身はより深く、より鮮やかに星々を宿すようになった。  

「残りは、あと三つ……『昏の欠片』『宵の欠片』『暁の欠片』」  
セレネが指折り数え、アルトに視線を向ける。  
「次は、砂漠の遺跡都市『黄昏の都』だ。 dort 『昏の欠片』が眠っている」  

アルトは剣を鞘に収め、王都の夜空を見上げた。氷の結晶が星光を受け、虹色に輝いている。  
「ああ。次も、その次も、俺たちの剣で切り開く」  

二人の背中は、吹きすさぶ冷風の中でも、決して揺るぐことはなかった。  
暁の剣が、虚無の夜を切り裂くその日まで。
