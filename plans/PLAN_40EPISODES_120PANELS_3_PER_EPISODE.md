# 40話120パネル（3コマ/話）修正計画書

## 提案概要
**40話 × 3コマ = 120コマ総数** という形式に変更。
1話あたり3コマの縦長ストーリーストリップ形式で、エピソード単体の完結性を保ちつつ生産効率を大幅に向上。

## なぜこれが現実的か

### 生産効率の劇的向上
| 項目 | 元計画 (24コマ/話) | 新計画 (3コマ/話) | 改善率 |
|------|-------------------|------------------|--------|
| 総コマ数 | 960コマ | 120コマ | **87.5%削減** |
| 生成API呼び出し | 960回 | 120回 | **87.5%削減** |
| 推定コスト | ~$32.64 | ~$4.08 | **87.5%削減** |
| 推定生成時間 | 2-3時間/話 | 15-20分/話 | **85-90%削減** |
| 品質ゲート負荷 | 高（24コマ/話） | 低（3コマ/話） | 大幅軽減 |

### ストーリー適合性
3コマ形式は古典的な新聞コマ漫画やWeb漫画で実証済みのフォーマット：
- **コマ1**: 導入・状況提示（Setup）
- **コマ2**: 発展・転換（Development/Turn）  
- **コマ3**: オチ・結末（Punchline/Conclusion）

これは「エピソード単体の流れがよく分かる」要件と完全に適合。

## 修正された実装戦略

### 1. フォーマット変更：3コマ縦長ストリップ
- **レイアウト**: 1列×3行の縦長（Webtoon形式に近い）
- **パネル比率**: 各コマ 1:1 または 4:3 の正方形～縦長
- **全体アスペクト比**: 1:3 または 4:9（縦長スクロール前提）
- **読み順**: 上→下（自然なスクロール挙動）

### 2. コマ別役割定義（エピソード内でのストーリーフロー）
| コマ番号 | 役割 | 目的 | 典型的構図 |
|----------|------|------|------------|
| **コマ1** | 導入（Setup） | シーン・キャラクター・日常状況を提示 | 引き〜中景、環境説明重視 |
| **コマ2** | 発展（Development） | 変化・問題・アクションの開始 | 中景〜寄り、キャラクター反応・動作 |
| **コマ3** | オチ（Punchline） | 結末・驚き・感情のクライマックス | 寄り〜極寄り、表情・効果音重視 |

### 3. ナノバナナ2ライト最適化アプローチの維持
コア戦略は変更せず、パネル数削減によりさらに効率化：

```
フェーズ0: マスターアセット準備（参照画像群）
        ↓
フェーズ1: 話ごとの3コマストーリーボード→プロンプト生成
        ↓
フェーズ2: 個別コマ生成（参照画像＋プロンプト ×3回/話）
        ↓
フェーズ3: ローカル縦長合成（1×3レイアウト＋ガター＋番号）
        ↓
フェーズ4: 品質ゲート＆ポストプロセス
        ↓
最終出力: 3コマ縦長ストリップ画像
```

### 4. 品質ゲートの簡素化
3コマのため、チェック項目は同様だが負荷が軽減：
- キャラ一貫性（CLIPスコア）: コマあたり1回 → 話あたり3回
- グリッド検出: 1×3レイアウト検出（簡素版）
- 番号認識: 上→下の順序確認
- リロール頻度: 劇的に低減（1話あたり最大3コマしかないため）

## 具体的プロンプトテンプレート（3コマ版）

### ベースプロンプト構造
```text
[character_ref] [environment_ref]
[episode_specific_action], [shot_type], [lighting], [mood],
manga panel, clean lineart, screentone shading,
consistent with reference images --no frame, no border, no text
```

### 3コマ別プロンプト例（エピソード: 「遅刻しそうな朝」）
**コマ1（導入）**:
```text
(char_ref/protagonist_master.png) (env/bedroom_morning.png)
protagonist sleeping in bed, alarm clock ringing 7:00 AM, 
wide shot, morning light, sleepy expression,
manga panel, clean lineart, screentone shading,
consistent with reference images
```

**コマ2（発展）**:
```text
(char_ref/protagonist_master.png) (env/bedroom_morning.png)
protagonist jumping out of bed, hair messy, looking at clock 7:58 AM, 
medium shot, urgent lighting, panicked expression,
manga panel, clean lineart, screentone shading,
consistent with reference images
```

**コマ3（オチ）**:
```text
(char_ref/protagonist_master.png) (env/front_door.png)
protagonist running out door with toast in mouth, 
closeup, dynamic motion lines, determined yet humorous expression,
manga panel, clean lineart, screentone shading,
consistent with reference images
```

## リスクと対策（修正版）

| リスク | 影響度 | 対策 |
|--------|--------|------|
| **3コマでのストーリー表現限界** | 中 | ストーリーボードテンプレートライブラリで型化（「日常トラブル型」「誤解型」「小さな勝利型」等） |
| **キャラ一貫性のハードル低下** | 低 | 実際は参照画像依存度が上がるため、一貫性は向上する可能性 |
| **読者飽き（フォーマット単調）** | 低 | 背景変化・カメラワーク変化・エフェクトバリエーションで対策 |
| **印刷物としての見栄え** | 低 | 後で4話分を1ページにまとめる等の再編集フローを別途準備 |
