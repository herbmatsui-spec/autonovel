## 1. システム概要とデータフロー

### システム概要
WindowsアプリケーションとしてUSBドライブを監視し、新規PDFファイル（手書きマニュアルのスキャンデータ）を検出したら、Google Cloud Vision APIでOCR処理を行い、抽出したテキストをGoogle Gemini APIで初心者向けに要約・構造化し、その結果をPDF、Word文書、音声ファイル（要点のみ）として出力ディレクトリに保存するアプリケーション。

### データフロー
1. USBドライブ監視モジュール → 新規PDFファイル検出
2. PDF処理モジュール → PDFから画像抽出（1ページ＝1画像）
3. Google Cloud Vision OCR → 画像から日本語テキスト抽出（手書き+英数字対応）
4. テキスト結合モジュール → 全ページのテキストを結合
5. Google Gemini API → テキストを初心者向けに要約・構造化（見出し・箇条書き形式）
6. 出力生成モジュール：
   - PDF生成モジュール → 整形済みテキストからPDF作成
   - Word生成モジュール → 整形済みテキストから.docx作成
   - 音声生成モジュール → 要点のみを音声ファイル（MP3）に変換
7. 出力ディレクトリ → 生成ファイルを保存（元PDF名_出力形式.拡張子）

データフロー図:
[USB監視] → [PDF処理] → [Vision API OCR] → [テキスト結合] → [Gemini API] → [出力生成] → [出力ディレクトリ]

                                                                   ├─ Word出力
                                                                   └─ 音声出力
