# archive/

このディレクトリには、リファクタリング・アーキテクチャ変更により現在のメインパスから移動した旧コード・実験的実装・非推奨モジュールが保存されています。

## 保存理由

- Git 履歴から削除せず、過去の実装を参照できるよう保持
- 将来の機能復活や比較検証時に活用可能
- 実験的実装（streamlit_retired_v2 等）のアーカイブ

## 内容

- `services_legacy/` - 旧サービス実装
- `streamlit_retired_v2/` - Streamlit v2 版デモアプリ
- `plans/` - 旧実装計画書
- `proposals/` - 機能提案・設計ドキュメント
- `hooks.py`, `cost.py`, `collab.py` 等 - 旧ユーティリティ

## 注意

このディレクトリ内のコードは**本番環境では使用されません**。メインパス (`src/`) の実装のみが正規版です。
