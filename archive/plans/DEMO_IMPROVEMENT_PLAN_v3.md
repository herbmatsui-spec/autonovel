# 覇権小説エンジン デモ改善計画書 v2 → v3

## 1. 現状の厳しい評価（v2）

| # | 問題点 | 証拠 |
|---|--------|------|
| 1 | 上級者モードが体験できない（READMEは2モードを謳う） | ステップ1はかんたんモードのみ |
| 2 | 生成文が一括表示されLLMストリーミングを再現していない | `novelContent.textContent = novel.content` 一括代入 |
| 3 | エラー状態が死蔵（定義のみで発火しない） | `errorBox`/`retryGeneration` に呼び出しなし |
| 4 | 進捗バーが実処理と同期していない | `setInterval` ランダム増加と `processStep` が独立 |
| 5 | メトリクスが非現実的・非再現（毎回変動） | `elapsed*150` に `creativity` 未反映 |
| 6 | 資産化パック/エクスポート不在 | EPUB/PDF/MOBI/ZIP/メディアミックス未表示 |
| 7 | SpiceGuardが静的リスト（仕組みが見えない） | マーカー注入→リライト→除去が非表示 |
| 8 | アクセシビリティ不備 | 全ラジオ tabindex=0、矢印キー無し、reduced-motion未対応 |
| 9 | IFルート（分岐）未表示 | READMEの「IFルート生成」が未反映 |

## 2. 改善点 9 つと実装方針

### 改善① 上級者モードの追加
- モード切替タブ（かんたん / 上級者）を追加
- 上級者モードでは「プロット編集テキストエリア」「文章の濃さスライダー(1-5)」「話数スライダー」「NSFWオプトインチェック」を表示
- プロット入力は生成される小説の「あらすじ」に反映、濃さ/話数は本文構成に影響

### 改善② ストリーミング生成（タイピング）効果
- 結果本文を数文字ずつ順次表示する typeWriter を実装し、実LLMのSSEストリーミング出力を再現
- `prefers-reduced-motion` 時は即時全文表示

### 改善③ エラー状態の実際の発火とリカバリー
- 設定に「不安定モード（エラーを発生させる）」チェックを追加
- オンの場合、生成中に 429 レートリミット / タイムアウトをランダム発生させ、エラー表示→「再試行」でリトライ（retryAttempts 増加・自動回復）

### 改善④ 進捗バーとステップの完全同期
- ランダム増加の `setInterval` を廃止し、処理済テキスト数 / 全テキスト数 で進捗を算出
- ステップ完了とバーが常に一致

### 改善⑤ 現実的・再現可能なメトリクス
- `computeMetrics(genre, creativity, length, chapters)` で固定式から tokens/コスト/時間を算出（創造性・文字数・話数を反映、毎回同一）
- 生成中は進捗比率でカウントアップ表示

### 改善⑥ 資産化パック・エクスポートのショーケース
- 結果画面に「EPUB/PDF/MOBI 書き出し」「資産化パック(ZIP)」「メディアミックス台本」ボタン
- デモ用に実際に Blob ダウンロードを発行（EPUB/PDF/MOBI は .md で出力し注記、ZIPは統合 .md、台本は .md）
- 「クリップボードにコピー」ボタンも追加

### 改善⑦ SpiceGuard マーカー機構の可視化
- 「尖り保護のしくみ」展開セクションで 3 フェーズ（注入→リライト→除去）をアニメーション表示
- 本文から尖り要素を抽出し `<<<SPICE:type>>>…<<</SPICE>>>` マーカーで囲み、除去後は黄色ハイライトで保護されたことを示す

### 改善⑧ アクセシビリティ強化
- ラジオをロービングタブインデックス化（選択/最初のみ tabindex=0、残り -1）
- 矢印キーでジャンル間を移動・選択
- `prefers-reduced-motion` で全アニメーション無効化、フォーカスリング明確化

### 改善⑨ IFルート（分岐ストーリー）プレビュー
- ジャンル別の分岐定義（カタルシス分岐/隠しルート/バッドエンド/真エンド等）をツリー表示
- 結果画面に「IFルート」セクションとして描画

## 3. 実装スケジュール

- フェーズA（構造・モード）: 改善①⑧（タブ・ラジオ・reduced-motion）
- フェーズB（生成・同期）: 改善②④⑤（ストリーミング・進捗同期・メトリクス）
- フェーズC（エラー・エクスポート）: 改善③⑥（不安定モード・Blobダウンロード）
- フェーズD（展示機能）: 改善⑦⑨（SpiceGuard・IFルート）

## 4. 成功指標
1. 上級者モードでプロット/濃さ/話数が出力に反映される
2. 本文がストリーミング表示され、reduced-motion で即時表示
3. 不安定モードでエラー→再試行が動作し retryAttempts が増加
4. 進捗バーがステップ処理と一致
5. 同じ入力でメトリクスが再現する
6. EPUB/PDF/MOBI/ZIP/台本のダウンロードが発行される
7. SpiceGuard の 3 フェーズが可視化される
8. 矢印キーでジャンル選択可能、reduced-motion 対応
9. IFルートがジャンル別に表示される

## 5. リスクと対応
- 複雑化 → モード切替でオプションを隠し、基本体験を損なわない
- ダウンロードの互換性 → Blob + a[download] で全モダンブラウザ対応
- 過剰アニメーション → reduced-motion で無効化
