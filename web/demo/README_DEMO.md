# AutoNovel かんたんモード デモ

このデモは、AutoNovelのかんたんモードを体験できる自己完結型のHTMLデモです。
バックエンドサーバー不要で、ブラウザがあればすぐに物語創作を体験できます。

## 特徴

- 🎲 企画ガチャでストーリーアイデア生成
- 🔮 逆算プロットビルダーでプロット構造作成  
- 👤 キャラクター設定と冒頭テキスト入力
- ⚡ リアルタイム速筆（ストリーミングプレビュー）
- 🪄 かんたん執筆開始（バックグラウンド生成）
- 📖 生成結果のプレビューと次話提案表示
- 📦 納品パッケージ（テキストファイル）ダウンロード
- 🚀 上級者Studioへの昇格案内
- 📚 ステップバイステップチュートリアルモード

## 使い方

1. `index.html` をブラウザで開く
2. 「チュートリアルモード」ボタンでステップバイステップのガイドを有効にできる（オプション）
3. 各ステップを順に進めて物語を創作する
4. 完成したら「納品パッケージ (ZIP) ダウンロード」で結果を保存

## デモの構成

- `index.html` - メインデモページ
- `style.css` - スタイルシート  
- `script.js` - メインロジック
- `mock-data.js` - モックデータ（ガチャ結果、プロット等）

## ブラウザ対応

- Chrome 推奨
- Firefox, Safari, Edge も対応
- モバイルデバイスでも快適に操作可能

## 注意点

- このデモはモックデータを使用しており、実際のAI生成ではありません
- 実際のAutoNovelでは、より高品質なAI生成と多機能が利用できます
- 本デモは教育・体験目的で作成されています
