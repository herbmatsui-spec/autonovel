# AutoNovel かんたんモード HTML デモ 実装計画書

## 目的
初心者でも分かりやすくAutoNovelのかんたんモードを学べるよう、自己完結型のHTMLデモを作成する。バックエンド不要で動作し、ステップバイステップのチュートリアル形式で操作方法を習得できる。

## 対象ユーザー
- AI小説執筆ツールを初めて使う人
- プログラミング知識不要のビジュアルツールを求める人
- AutoNovelの基本機能を体験したい人

## デモの特徴
1. **自己完結型**: 単一のHTMLファイル（CSS/JS内蔵）または最小限のファイル構成
2. **オフライン動作**: モックデータを使用し、バックエンドサーバー不要
3. **ステップバイステップチュートリアル**: 初心者向けの詳細な説明付き
4. **インタラクティブ**: 実際に操作しながら学べる体験型
5. **モバイルレスポンシブ**: スマートフォンでも快適に操作可能

## 実装範囲
AutoNovelのかんたんモードのコア機能を体験できる以下のフローを実装:
1. 企画ガチャでストーリーアイデア生成
2. 逆算プロットビルダーでプロット構造作成
3. 直接入力でキャラ設定・冒頭テキスト入力
4. リアルタイム執筆開始（ストリーミングプレビュー）
5. かんたん執筆開始（バックグラウンド生成）
6. 生成結果のプレビューと次話提案表示
7. 納品パッケージ（ZIP）ダウンロード
8. 上級者Studioへの昇格案内

## 技術スタック
- HTML5 + CSS3 + Vanilla JavaScript (フレームワーク不要)
- LocalStorageによる状態保持
- CSS Animationsとトランジション
- アクセシビリティ対応（ARIA属性、十分なコントラスト）
- モバイルファーストレスポンシブデザイン

## UI/UX設計ガイドライン

### カラースキーム
- メインカラー: #3B82F6 (ブルー) - 信頼性と落ち着き
- アクセントカラー: #10B981 (エメラルド) - 成功と創造性
- 警告カラー: #EF4444 (レッド) - エラーと注意
- 背景: #1F2937 (ダークグレー) - 目の疲れ軽減
- テキスト: #F9FAFB (ライトグレー) - 高コントラスト

### タイポグラフィ
- フォントファミリー: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif
- モノスペース: 'Consolas', 'Monaco', 'Courier New', monospace (コード・プレビュー用)
- フォントサイズ: 基準16px、見出し1.5-2倍、本文1倍

### コンポーネント設計
1. **ヘッダー**: プロジェクト名と現在のステップ表示
2. **メインコンテンツエリア**: ステップ別コンテンツを表示
3. **サイドバー**: 進行状況とヘルプボタン（モバイルでは下部に移動）
4. **フッター**: copyrightとリンク
5. **モーダル**: ガチャ結果、プロット詳細、確認ダイアログ用
6. **トースト**: 成功/エラー/情報メッセージの一時表示

## アクセシビリティ対応
- すべてのインタラクティブ要素に適切なaria-label
- キーボードナビゲーション完全対応（Tab, Enter, Escape）
- 十分なコントラスト比（WCAG AA基準達成）
- スクリーンリーダー対応のライブリージョン
- フォーカスリングの視認性確保
- 画像には適切なalt text

## パフォーマンス最適化
- CSSアニメーションはwill-changeとtransformを使用
- 画像は必要最小限（SVGアイコン優先）
- JavaScriptは非同期読み込みと遅延実行
- LocalStorageへの書き込みは必要最小限に抑える
- 大きなデータセットは仮想スクロール実装検討

## エラーハンドリング
- ネットワークエラー（モックでもシミュレート）
- 入力バリデーションエラー
- タイムアウトエラー（生成シミュレーション用）
- リカバリー手段の明確な提示（再試行ボタン等）

## テスト戦略
1. **機能テスト**: 各ステップの機能が正しく動作するか
2. **ユーザビリティテスト**: 初心者が迷わず操作できるか
3. **互換性テスト**: 主要ブラウザでの動作確認
4. **アクセシビリティテスト**: スクリーンリーダーとキーボードのみでの操作確認
5. **パフォーマンステスト**: ローディング時間とアニメーションの滑らかさ

## デプロイ方法
GitHub PagesまたはNetlifyに静的サイトとしてデプロイ可能。
ビルド不要の純粋なHTML/CSS/JSのため、任意の静的ホスティングサービスで動作。
